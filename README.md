# 후방 접근 감지 모듈

카메라와 레이더를 활용해 사용자의 후방에서 접근하는 객체를 감지하고, 진동과 LED로 접근 방향과 위험 정보를 전달하는 **착용형 후방 감지 시스템** 캡스톤 디자인 프로젝트입니다.

> 현재 설계·개발을 진행하기 위한 구성을 정리한 문서입니다. 아래 부품과 통신 방식은 최근 논의한 설계안이며, 구현 및 실험 결과에 따라 변경될 수 있습니다.

## 프로젝트 목적

- 사용자가 직접 확인하기 어려운 후방의 접근 상황을 파악합니다.
- 카메라의 객체 종류 정보와 레이더의 거리·속도 정보를 함께 활용합니다.
- 좌우 접근 방향을 구분해 진동과 LED로 알림을 전달하는 것을 목표로 합니다.
- 외부 공유기 없이 사용할 수 있는 로컬 통신 구조와 착용 가능한 모듈 구성을 검토합니다.

## 시스템 구성

```text
[좌측 후방 감지 모듈] ── Wi-Fi ──┐
 XIAO ESP32-S3 Sense            │
 카메라 + C4001 레이더           │
                               ├── [Raspberry Pi 5] ── BLE ── [알림 모듈]
[우측 후방 감지 모듈] ── Wi-Fi ──┘    객체 인식·위험 판단          ESP32-S3
 XIAO ESP32-S3 Sense                 Wi-Fi 핫스팟                진동모터
 카메라 + C4001 레이더                                           LED 매트릭스
```

| 구성 요소 | 사용 부품·기술 | 역할 |
| --- | --- | --- |
| 좌측·우측 감지 모듈 | XIAO ESP32-S3 Sense, 카메라, C4001 레이더 | 후방 이미지 및 레이더 데이터 수집·전송 |
| 중앙 처리 장치 | Raspberry Pi 5 | 이미지·레이더 데이터 수신 및 통합 처리 |
| 객체 인식 | YOLO 기반 모델, YOLO11n 검토 | 후방 객체 종류 식별 |
| 알림 모듈 | 별도 ESP32-S3, 진동모터, LED 매트릭스 | 접근 방향과 위험 알림 전달 |
| 감지 모듈 → 중앙 장치 | Wi-Fi | 이미지 및 레이더 데이터 전송 |
| 중앙 장치 → 알림 모듈 | BLE | 위험도·방향 등 경고 데이터 전송 |

## 동작 흐름

1. 좌우 감지 모듈이 후방 이미지를 촬영하고 레이더 측정값을 수집합니다.
2. 각 모듈이 Raspberry Pi 5의 Wi-Fi 핫스팟에 연결해 데이터를 전송합니다.
3. Raspberry Pi 5가 YOLO 기반 객체 인식 결과와 레이더 정보를 통합합니다.
4. 접근 방향과 위험도를 판단한 뒤 알림 모듈로 경고 데이터를 전달합니다.
5. 알림 모듈이 진동과 LED로 사용자에게 정보를 제공합니다.

## 통신 및 이미지 전송 구상

- **Wi-Fi:** 좌우 감지 모듈에서 Pi 5로 이미지와 레이더 데이터를 전송하는 방식입니다. Pi 5 자체 핫스팟을 활용하는 구성을 검토합니다.
- **BLE:** Pi 5에서 별도 ESP32-S3 알림 모듈로 경고 정보를 전송하는 용도로 사용합니다.
- **이미지 전송 주기:** 연속 영상 대신 0.5~1초 간격의 JPEG 전송을 검토 중입니다.
- **상황별 촬영 주기:** 레이더가 접근을 감지할 때 촬영 빈도를 높이는 방안도 검토합니다. 실제 적용 여부는 처리량과 지연을 측정한 뒤 결정합니다.
- **센서 역할:** 레이더의 접근 정보를 활용하고, 카메라 인식 결과로 객체 종류를 보완하는 방향으로 설계합니다.

최종 촬영 주기, 데이터 형식, 위험 판단 기준은 아직 확정하지 않았습니다.

## 하드웨어 제작 방향

- 개발 단계에서는 핀 헤더와 점퍼선을 활용해 부품 교체와 연결 테스트를 진행합니다.
- 착용 중 움직임으로 연결이 빠지지 않도록 커넥터 고정과 배선의 장력 분산을 고려합니다.
- 최종 모듈은 직접 납땜 또는 잠금형 커넥터 등 소형화와 정비성을 고려한 연결 방식을 검토합니다.
- 구체적인 전원·GPIO·배선은 부품 사양과 실제 보드 구성을 확인한 뒤 문서화합니다.
